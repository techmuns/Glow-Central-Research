# Glow Ventures branding

Glow uses a local gold-and-ink SVG wordmark and a compact G favicon. These are
code-native assets; they do not reference Sattva artwork or remote image hosts.
The service worker warms both for offline repeat visits. Keep the natural aspect
ratio. Shared CSS class names remain compatible with the upstream template.

The light palette is in `scripts/glow-palette.cjs` and `public/css/glow.css`.
The shared semantic dark theme remains in place; source dates and status colours
retain their separate meanings.
